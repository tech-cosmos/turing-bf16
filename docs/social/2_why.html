bf16 on Turing: three bad options

✕

Run bf16 as-is

Slower than fp32. Attention runs out of memory at long context.

✕

Overflows past 65,504. Gemma 3 4B → NaN.

✕

Run in fp32

2× the memory, still slow.

✓

~10× faster, bf16 accuracy.
